# ACTIVIDAD 3 – TEORÍA DE COLAS

## 1. Descripción

Esta actividad desarrolla una simulación de un sistema de teoría de colas, con el propósito de representar y analizar el comportamiento de una fila de atención, considerando la llegada de usuarios y el proceso de servicio.

Mediante herramientas de programación y análisis de datos se busca comprender el funcionamiento del sistema, observar sus resultados e interpretar el comportamiento de los tiempos de espera y la atención.

## 2. Objetivo

Implementar y analizar un modelo de simulación de teoría de colas, utilizando herramientas computacionales para representar el proceso de atención y estudiar los resultados obtenidos.

## 3. Herramientas utilizadas

- Python: desarrollo del código de simulación.
- Google Colab: ejecución del notebook.
- Excel: organización y análisis de resultados.
- GitHub: almacenamiento y documentación del proyecto.

## 4. Estructura de la actividad

- `codigo/`: notebook y archivos de programación.
- `resultados/`: tablas, gráficos y archivos generados.
- `evidencias/`: capturas de pantalla de la ejecución y los resultados.

## 5. Archivos del proyecto

En este repositorio se encuentran los siguientes recursos:

- Código fuente de la simulación.
- Archivo Excel con los datos y resultados.
- Informe académico en formato PDF.
- Evidencias del desarrollo y ejecución.

## 6. Instrucciones de ejecución

1. Descargar el notebook de Python desde la carpeta `codigo/`.
2. Abrir Google Colab.
3. Cargar el notebook.
4. Verificar que los archivos de datos requeridos estén disponibles.
5. Ejecutar las celdas en orden.
6. Revisar las tablas, gráficos y resultados generados.
