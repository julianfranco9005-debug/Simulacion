**Repositorio académico – Ingeniería de Software y Datos**

Este repositorio contiene el desarrollo de las actividades y proyectos realizados en la asignatura **Simulación**, correspondiente al quinto semestre, durante el semestre académico 2026-2, bajo la orientación del profesor **Julián Andrés Loaiza**.

## Objetivo del repositorio

Organizar y documentar las actividades desarrolladas durante el curso, incluyendo los códigos fuente, archivos utilizados, resultados obtenidos, evidencias de ejecución e instrucciones para reproducir los ejercicios de simulación.

## Organización del repositorio

Las actividades se organizarán en carpetas independientes:

| Carpeta | Descripción |
|---|---|
| `ACTIVIDAD_1_TAHTZEE` | Desarrollo de la primera actividad del curso. |
| `ACTIVIDAD_2_MONTECARLO` | Desarrollo de ejercicios de simulación Monte Carlo. |
| `ACTIVIDAD_3_TEORIA_DE_COLAS` | Desarrollo de la simulación de teoría de colas. |
| `ACTIVIDAD_4_POR_DEFINIR` | Espacio destinado a la cuarta actividad del curso. |

## Contenido de las actividades

Cada actividad incluirá, según corresponda:

- Código fuente y notebooks.
- Archivos de datos y recursos necesarios.
- Resultados, tablas y gráficas.
- Evidencias de ejecución.
- Archivo README con descripción e instrucciones de ejecución.

## Herramientas utilizadas

- Python.
- Google Colab.
- GitHub.
- Excel.

## Ejecución de los proyectos

Las instrucciones específicas de ejecución se documentarán en el README de cada actividad, indicando las herramientas necesarias, los archivos requeridos y los pasos para ejecutar los ejercicios.
